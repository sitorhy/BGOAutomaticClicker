# 仓检项目
该项目用于扫描仓库截图，分割出从者头像卡片。

# 项目的实验蓝图
+ res目录存放了仓库界面从顶部滚动到底部的截图，识别出所有卡片的范围，并排除掉滚动过程中不完整的卡片。
+ 分割出的卡片范围可以裁剪出头像卡片，头像卡片可以作为其他头像模型的输入。
+ 头像识别不是本子项目的职能。


# 阶段性结论
+ 使用轮廓检测定位卡片边框
边框的色彩比较鲜艳，截图转为HSV颜色模型后提取饱和度（V）通道后进行形态学处理后提取轮廓，合并重合轮廓的矩形范围。
能适配部分截图，但对铜卡效果非常差。立绘本身对比度不够的情况下，难以控制阈值，有可能二值化处理后立绘只剩下几个像素点。
+ 使用等级文字进行定位
进行全局ORC，识别“等级100”等位置，效果比形态学处理要好，能识别90%左右的卡片文字位置，但文字的特征不稳定，文字会变化跟立绘背景融合较为紧密，对比度相似的情况下背景会干扰文字识别，甚至识别不出。
+ 模板匹配
除了慢没有什么明显缺点
+ 最终方案是还是免不了目标检测训练
新的想法，有的卡根本抽不到，所以无法完全依赖截图，因为无法提供，实际上只要随便准备一些风景图，再随机案一定的缩放比例或角度安放徽标即可，这样的方案还可以用于合成测试图。
思路是将壁纸划分为 n x m 的区域，间隔 80 防止重合，然后再网格区域随便放就行了，还可以控制哪些类别有哪些可以没有。
